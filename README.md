### ما الذي يجعله أفضل من الطريقة اليدوية؟
- **صفر نسخ ولصق** بين 5 مواقع — كل شيء داخل تطبيق واحد.
- **حلقة جودة**: الناقد يرفض السيناريو الضعيف ويعيده للكاتب تلقائيًا.
- **توقيت الصوت مع الصورة والترجمة تلقائي** (الجزء الأصعب في المونتاج اليدوي).
- **بدون اشتراك CapCut Pro**: الترجمة والتأثيرات والتصدير مجانية داخل التطبيق.
- **طابور إنتاج**: اطلب 5 أو 10 فيديوهات مرة واحدة.
- **بوابة موافقة**: يصلك كل فيديو على **تيليجرام** وفي تبويب "المراجعة"؛ توافق، أو تكتب ملاحظة ويعيد الفريق العمل من المرحلة التي تختارها (السيناريو، الصور، الصوت، المونتاج).
- **يعمل فورًا بدون أي مفاتيح** (وضع تجريبي بقصص جاهزة ورسام محلي) للتجربة.

## التثبيت

### 📱 على الهاتف أو 💻 الكمبيوتر (الأسهل — تطبيق ويب قابل للتثبيت)
1. فعّل GitHub Pages للمستودع: **Settings → Pages → Source: GitHub Actions**.
2. سيُنشر التطبيق تلقائيًا (workflow: `Deploy web app`) على رابط مثل `https://<اسمك>.github.io/video/`.
3. افتح الرابط:
   - **أندرويد / كروم / إيدج على الكمبيوتر**: اضغط "⬇️ تثبيت التطبيق" أو "Install app".
   - **آيفون**: زر المشاركة ← "إضافة إلى الشاشة الرئيسية".

### 🖥️ ملف تثبيت للكمبيوتر (.exe / .dmg / .AppImage) و 🤖 أندرويد (.apk)
من تبويب **Actions** شغّل workflow **Build apps** (أو ادفع وسمًا مثل `v1.0.0`)، ثم نزّل الملفات من قسم Artifacts.

أو محليًا:
```bash
cd desktop && npm install && npm start      # تشغيل
npm run dist                                  # إنشاء ملف التثبيت
```

### تشغيل سريع بدون تثبيت
```bash
cd app && python3 -m http.server 8080   # ثم افتح http://localhost:8080
```

## الإعدادات (من تبويب 🔑 داخل التطبيق)
| الخدمة | لماذا | مطلوب؟ |
|---|---|---|
| **Claude API** (console.anthropic.com) | عقل الفريق: البحث، الكتابة، النقد، الإخراج، SEO | موصى به بشدة (بدونه = وضع تجريبي) |
| **ElevenLabs** + Voice ID | تعليق صوتي بشري بالعربية واللهجات | موصى به |
| **الصور**: Pollinations (مجاني) أو OpenAI | رسم المشاهد | Pollinations لا يحتاج مفتاحًا |
| **تيليجرام** (Bot Token + Chat ID) | يرسل لك الفيديو الجاهز على هاتفك للمراجعة | اختياري |
| **Google OAuth Client ID** | النشر المباشر على يوتيوب بعد الموافقة | اختياري (وإلا تنزّل الفيديو وتنشره بنفسك) |

> المفاتيح تُحفظ على جهازك فقط، وتُرسل مباشرة لكل خدمة.

## ملاحظات مهمة
- المونتاج يتم داخل الجهاز ويستغرق تقريبًا **مثل مدة الفيديو** (دقيقة لفيديو Short). أبقِ التطبيق مفتوحًا أثناء ذلك (نسخة الكمبيوتر تستمر حتى لو صغّرت النافذة).
- يصدّر الفيديو بصيغة MP4 أو WebM حسب المتصفح؛ يوتيوب وتيليجرام يقبلان الاثنين. لتيك توك يُفضل كروم/نسخة الكمبيوتر (MP4).
- في قصص الجريمة الحقيقية يُطلب من الكاتب الالتزام بالوقائع وعدم اختلاق تفاصيل عن أشخاص حقيقيين.
