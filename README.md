## التشغيل على حاسوبك (ويندوز/ماك/لينكس)
1. سطّب **Python 3.10+** و **ffmpeg** (ويندوز: `winget install ffmpeg`، ماك: `brew install ffmpeg`).
2. في فولدر المشروع:
   ```bash
   pip install -r requirements.txt
   python run_factory.py
   ```
3. افتح `http://localhost:8765` ← **الإعدادات** ← حط مفتاح Anthropic API ← حفظ.
4. **التشغيل** ← اكتب موضوع ← «ابدأ التصنيع». أو جرّب «تجربة بدون مفتاح API» الأول.

### من الموبايل
- نفس الواي فاي: افتح الرابط اللي بيظهر في الشاشة (`http://<ip-الحاسوب>:8765`). **حط كلمة سر للوحة الأول.**
- من أي مكان: اعمل بوت تيليجرام وحط التوكن في «الربط ← التحكم من الموبايل»، وابعت `/video الموضوع` أو `/auto 3`.

### أوامر بدون لوحة
```bash
python run_factory.py make "ليه السواقة في إنجلترا على الشمال؟" "ليه الفيشة مختلفة في كل بلد؟"
python run_factory.py auto -n 5      # المصنع يختار 5 مواضيع
python run_factory.py demo           # تجربة كاملة بدون مفتاح
```

## 🔌 تغيير الربط (المنصات والتطبيقات)
من تبويب **الربط بالمنصات**: ضيف/احذف/اقفل أي رابط، وزرار **اختبار** لكل واحد. الأنواع:

| النوع | ينفع لإيه |
|---|---|
| 📁 مجلد على الحاسوب | ينسخ الفيديو والشورتس والثامبنيل والوصف لأي فولدر (حتى فولدر جوجل درايف/دروبوكس/OneDrive المتزامن) |
| 💻 أمر على الحاسوب | أي برنامج: `rclone`، `adb push` للموبايل، سكريبت خاص بيك |
| 🔗 Webhook | n8n / Make / Zapier / IFTTT ← أي تطبيق في الدنيا (إنستجرام، شيتس، نوشن…) |
| ✈️ تيليجرام | يبعتلك الفيديو والشورتس على موبايلك |
| 🎮 ديسكورد · 💬 سلاك | قنوات الفريق |
| 🔔 ntfy | إشعار فوري على الموبايل |
| 🟢 واتساب | رسالة عن طريق CallMeBot |
| ▶️ يوتيوب | رفع تلقائي + الثامبنيل + الشورتس ([الشرح](docs/connect-youtube.md)) |
| 📘 فيسبوك · 🎵 تيك توك | نشر على الصفحة / الشورتس على تيك توك |

عايز منصة جديدة؟ دالة واحدة في `factory/connectors.py` وتسجّلها في `TYPES` — اللوحة بتعمل الفورم لوحدها.

## ملفات مهمة
- `factory/style.py` — دليل الأسلوب المستخرج من الفيديو (عدّله لشخصية قناتك).
- `assets/music/` — حط ملفات موسيقى mp3 مسموح استخدامها (مثلاً من مكتبة يوتيوب الصوتية).
- `assets/fonts/` — خط Cairo (رخصة OFL).
- `output/jobs/` — كل فيديو وملفاته، `output/ready/` — الجاهز للنشر.

## ⚡ إضافات تخلي الشغل أسرع وأكتر
اتعمل منها جوه المصنع:
- **فيديوهات بالتوازي** (`فيديوهات في نفس الوقت`) ومشاهد بالتوازي جوه كل فيديو.
- **استكمال** من نقطة الوقوف بدل ما تبدأ من الأول.
- **شورتس تلقائي** من كل فيديو = محتوى ×2 بدون شغل زيادة.
- **وضع تلقائي** (`/auto 5`) والمصنع يفتكر المواضيع اللي عملها وما يكررهاش.
- **Prompt caching** لدليل الأسلوب = أرخص وأسرع في كل نداء.

مقترحات تضيفها بعد كده (بالترتيب حسب الفايدة):
1. **جدولة يومية**: Task Scheduler في ويندوز أو cron يشغّل `python run_factory.py auto -n 3` كل يوم الساعة 3 الفجر.
2. **نموذج أسرع للعمّال الخفاف**: من الإعدادات خلّي «النموذج السريع» = `claude-sonnet-5-5` أو `claude-haiku-5-5` (عمّال 1، 2، 14، 15) — أسرع وأرخص، والكتابة تفضل على الأقوى.
3. **صور بالذكاء الاصطناعي**: اربط أي API صور في «الإعدادات ← الصور» (أو ComfyUI على كارت الشاشة عندك) بدل البطاقات.
4. **صوت مميز للقناة**: ElevenLabs بصوت ثابت = هوية للقناة.
5. **دبلجة لغات تانية**: عامل إضافي يترجم السكريبت ويعيد الصوت = نفس الفيديو لقنوات إنجليزي/فرنساوي.
6. **ريندر بكارت الشاشة**: بدّل `libx264` بـ `h264_nvenc` في `factory/media.py` لو عندك NVIDIA = مونتاج أسرع بكتير.
7. **اختبار A/B للثامبنيل**: خلّي العامل 14 يطلع 3 ثامبنيلات وتجرّبهم بأداة Test & Compare في يوتيوب.
8. **مراجعة بشرية سريعة**: خلّي يوتيوب على `private`، وانت تراجع من الموبايل وتنشر بضغطة.
9. **Batch API** لو هتعمل 20+ فيديو مرة واحدة ومش مستعجل = نص التكلفة.
10. **عامل تحليلات**: يقرا أداء الفيديوهات اللي اتنشرت ويقول لكشّاف الأفكار إيه اللي ينفع أكتر.
