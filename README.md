# لِسان — تعلّم الألمانية والإنجليزية

تطبيق ويب بسيط (ملف واحد `index.html`) يعلّمك الكلام والنطق:

- كل جملة مكتوبة باللغة الأجنبية، ونطقها بالحروف العربية، ومقسّمة إلى مقاطع (المقطع الملوّن هو المشدد)، مع الترجمة ونصيحة نطق.
- زر **استمع** وزر **ببطء** لسماع النطق الصحيح.
- زر **انطق أنت**: يسمعك عبر الميكروفون ويقيّم نطقك كلمة بكلمة (يعمل في Chrome / Edge).
- **محادثات** قصيرة من الحياة اليومية، و**أصوات صعبة** يخطئ فيها العرب، و**اختبر نفسك**.
- **ترجم جملتك**: يعمل عند فتح التطبيق داخل Claude.

## التشغيل
افتح `index.html` في متصفح Chrome (على الكمبيوتر أو الهاتف). لا يحتاج تثبيت أي شيء.
