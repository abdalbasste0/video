النصوص المثبتة (LOCKED CHARACTER DESIGN، LOCKED IMAGE STYLE، CLOSER، الكراكتر شيت، الأنيميشن الماستر، خاتمة الثمبنيل) بيضيفها الكود نفسه، مش الموديل، عشان تفضل مطابقة حرفياً في كل برومت.

## التشغيل

**الأسهل (والموبايل):** افتح نسخة claude.ai من الموقع. بتشتغل على حسابك في Claude مباشرة من غير مفتاح API، وكل اللي محتاجه إنك توافق لما الصفحة تطلب تستخدم Claude.

**أو على أي سيرفر:**

موقع ثابت من غير build. افتحه من أي سيرفر استاتيك:

```bash
python3 -m http.server 8080
# افتح http://localhost:8080
```

أو فعّل GitHub Pages على الريبو.

أول مرة هيطلب منك **مفتاح Claude API**. المفتاح بيتحفظ في متصفحك بس (localStorage) وبيتبعت مباشرة لـ `api.anthropic.com` عن طريق Anthropic SDK الرسمي. الموديل الافتراضي Claude Opus 5.5، وتقدر تغيّره لـ Sonnet 5.5 أو Haiku 5.5 من الإعدادات.

المشروع بيتحفظ تلقائياً في المتصفح، فلو قفلت الصفحة هتكمل من نفس المحطة. تقدر تضغط على أي عامل تشوف شغله، أو تعيد تشغيله (وكل اللي بعده هيتعاد).

## الملفات

- `index.html` — أرضية المصنع وغرفة التحكم
- `css/style.css` — التصميم (فاتح/غامق، موبايل)
- `js/locked.js` — النصوص المثبتة حرفياً
- `js/workers.js` — تعريف الـ 15 عامل
- `js/api.js` — الاتصال بـ Claude
- `js/app.js` — محرك خط الإنتاج والواجهة
- `js/media.js` — ElevenLabs (صوت وصور) والتخزين في المتصفح
- `js/studio.js` — محرك الأنيميشن: رسم الستيك مان والخلفيات والحركات والترجمة والموسيقى وتسجيل الفيديو
