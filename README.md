# Shortcut HQ: شركة محتوى موظفوها ذكاء اصطناعي

شركة فيها **مديرة تنفيذية و15 موظفاً**، كلهم وكلاء ذكاء اصطناعي داخل Claude Code. تصنع فيديوهات في مجال **أدوات الذكاء الاصطناعي والإنتاجية** للسوق **الأمريكي والأوروبي**، وتنشرها على **YouTube وTikTok وInstagram وFacebook**.

أنت تكلّم المديرة **ياسمين** فقط، وهي توزّع الشغل على الفريق.

## الفريق

| الغرفة | الموظفون |
|---|---|
| جناح المديرة | ياسمين (المديرة التنفيذية)، سلمان (رئيس المكتب) |
| غرفة الكتّاب | فهد وليلى (صيد الترندات)، عمر (سكريبت الفيديو الطويل)، نورة (سكريبت القصير)، هالة (الهوك) |
| استوديو المونتاج | خالد (المونتاج)، ريم (الكابشن والترجمة للألمانية والفرنسية والإسبانية)، طارق (الغلاف) |
| غرفة التسجيل | مريم (التلقين وقائمة اللقطات) |
| مركز النشر | يوسف (النشر)، سارة (التحليل والسيو)، دانة (التعليقات والمجتمع) |
| غرفة الاجتماعات | بدر (مراجعة الجودة) |
| مكتبة GitHub | جود (مكتبة المهارات) |

## الأوامر

| الأمر | ماذا يفعل |
|---|---|
| `/ceo اصنعي فيديو اليوم` | تعطي المديرة أي مهمة، وهي تشغّل الفريق وتسلّمك النتيجة |
| `/brief` | ملخص الصباح: مهامك اليوم بالضبط (يعمل تلقائياً كل يوم الساعة 8) |
| `/sunday-meeting` | اجتماع الأحد: ماذا خرب، وكيف نصلحه، وكيف نتطور، ثم جولة مكتبة GitHub |
| `/approve T-001` | توافق على شغل، فيحصل الفريق على نقاط خبرة |
| `/approve T-001 رفض: السبب` | ترفض الشغل، فيعيده الفريق |
| `/publish <اسم المشروع>` | يجدول الفيديو المعتمد على المنصات الأربع |
| `/office` | يعرض حالة الفريق ويحدّث صفحة المكتب الحي |
| `/library` | يبحث عن مهارات جديدة في GitHub الآن |

## يومك في الشركة
1. الساعة 8 صباحاً يصلك الملخص في `company/briefs/`.
2. تسجّل الفيديو من ملف التلقين الجاهز `teleprompter.md`، وتضع المقطع الخام في `company/inbox/footage/`.
3. تكتب `/ceo مونتاج <اسم المشروع>`، فيقصّه خالد عمودياً 9:16 مع الترجمة، ويراجعه بدر.
4. تكتب `/approve` ثم `/publish`.

## المستويات
كل موظف يبدأ **متدرباً (Lv1)** ويصعد حتى **أسطورة (Lv10)**:
- كل مهمة يسلّمها: 10 نقاط خبرة.
- كل موافقة منك على شغله: 15 نقطة.
- كل مهارة جديدة يتعلّمها: 20 نقطة.

## المكتب الحي
- **نسخة ثابتة:** `python3 tools/company.py office` ثم افتح `office/dist/index.html` في المتصفح.
- **نسخة مباشرة تتحدّث كل 5 ثوانٍ:** `python3 -m http.server 8080` ثم افتح http://localhost:8080/office/

## الإعدادات
كل شيء في ملف `company/config.json`:
- المجال، ومعه 3 بدائل جاهزة.
- المنصات، ومواعيد النشر لنيويورك وباريس.
- توقيتك أنت لملخص الصباح.
- القواعد (الموافقات، والأدوات المدفوعة).

## القواعد
- لا شيء يُنشر، ولا تُصرف أي نقاط في أداة مدفوعة، بدون موافقتك.
- المهارات من GitHub نصوص فقط، ولا يُشغَّل أي كود غريب.
