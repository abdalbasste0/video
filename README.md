# 📄 ماسح PDF

تطبيق ويب (PWA) لمسح المستندات بكاميرا الهاتف وتحويل الصور إلى ملف PDF. يعمل بالكامل على جهازك، بدون خادم وبدون رفع أي صورة إلى الإنترنت.

## المزايا
- 📷 **تصوير مباشر** بالكاميرا الخلفية، أو اختيار عدة صور من المعرض (أو سحبها وإفلاتها على الحاسوب).
- 🪄 **كشف تلقائي لحواف الورقة** مع إمكانية تعديل الزوايا الأربع يدوياً، وتظهر عدسة مكبّرة أثناء السحب.
- 📐 **تصحيح المنظور**: الورقة المصوّرة بزاوية تصبح مستطيلة ومستقيمة.
- 🎨 **فلاتر**: محسّن (تبييض الخلفية وزيادة التباين)، أصلي، رمادي، أبيض وأسود (عتبة تكيّفية مناسبة للنصوص).
- ⟳ **تدوير** الصفحات، و**إعادة ترتيبها**، وحذفها.
- ⬇️ **تصدير PDF** بمقاس A4 أو Letter أو بحجم الصورة، مع ثلاث مستويات للجودة، والتنزيل أو **المشاركة** مباشرة (واتساب، بريد…).
- 💾 **حفظ تلقائي** للصفحات في المتصفح (IndexedDB)، فلا تضيع إذا أُغلق التطبيق.
- 📴 **يعمل بدون إنترنت** بعد أول فتح، ويمكن **تثبيته على الشاشة الرئيسية** كتطبيق.

## التشغيل
لا يحتاج إلى بناء أو أي مكتبات، فهو ملفات ثابتة فقط:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

لاستخدامه على الهاتف، انشره على أي استضافة ثابتة تعمل عبر HTTPS (مثل GitHub Pages أو Netlify أو Vercel)، ثم اختر من المتصفح «إضافة إلى الشاشة الرئيسية».

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` / `styles.css` | الواجهة (عربية، من اليمين لليسار، تدعم الوضع الداكن) |
| `app.js` | منطق التطبيق: الصفحات، المحرر، التخزين، التصدير |
| `scanner.js` | معالجة الصور: كشف الحواف، تصحيح المنظور، الفلاتر، التدوير |
| `pdf.js` | مولّد PDF مكتوب من الصفر يضمّن صور JPEG مباشرة |
| `sw.js` / `manifest.webmanifest` | العمل بدون إنترنت وإمكانية التثبيت |
