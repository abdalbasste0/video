# تشغيل المصنع على حاسوبك (ويندوز) — خطوة بخطوة

## 1) تسطيب البرامج (مرة واحدة)
افتح **PowerShell** واكتب:
```powershell
winget install Python.Python.3.12
winget install Gyan.FFmpeg
winget install Git.Git
```
اقفل PowerShell وافتحه تاني.

## 2) تنزيل المصنع
```powershell
cd $HOME\Desktop
git clone -b ccr-9aa7a850-kxiet8 https://github.com/abdalbasste0/video.git video-factory
cd video-factory
pip install -r requirements.txt
```

## 3) التشغيل
```powershell
python run_factory.py
```
افتح المتصفح على **http://localhost:8765**.

## 4) الإعدادات (تبويب «الإعدادات»)
| الخانة | القيمة |
|---|---|
| مفتاح Anthropic API | من https://console.anthropic.com ← API Keys (ده «عقل» عمّال الكتابة، مدفوع حسب الاستخدام) |
| نوع الفيديو | **قصة** |
| لغة الفيديو | English أو العربية |
| مزوّد الصوت | Edge (مجاني) ← صوت إنجليزي مثل `en-US-GuyNeural` أو عربي مثل `ar-SA-HamedNeural` |
| مولّد الصور | اختار من الجدول تحت |

اضغط **«حفظ»**، وبعدين **«🎨 جرّب توليد صورة»**. لو ظهرت صورة، الربط شغال.

## 5) اختيار مولّد الصور
فيديو قصة مدته 8 دقايق محتاج حوالي **100–130 صورة**.

| المولّد | التكلفة | الجودة والملاحظات |
|---|---|---|
| **Pollinations** | مجاني، بدون مفتاح | كويس للبداية. ممكن يبطّأ أو يرفض لو طلبت صور كتير مرة واحدة، فخلّي «صور في نفس الوقت» = 1 أو 2 |
| **fal.ai (FLUX schnell)** | رخيص جداً للصورة | سريع وجودة كويسة. المفتاح من fal.ai ← Keys |
| **OpenAI (gpt-image-1)** | أغلى | أحسن التزام بالوصف. المفتاح من platform.openai.com |
| **Stability AI** | متوسط | المفتاح من platform.stability.ai |
| **Stable Diffusion على جهازك** | مجاني | محتاج كارت شاشة NVIDIA قوي. شغّل AUTOMATIC1111 بـ `--api` |

> الأسعار بتتغير، فشوف صفحة الأسعار في موقع كل خدمة قبل ما تبدأ.

**نصيحة:** ابدأ بـ Pollinations وجرّب فيديو واحد. لو الشكل عجبك كمّل بيه، ولو محتاج جودة أعلى انتقل لـ fal.ai.

## 6) عمل الفيديو
تبويب **«التشغيل»** ← اكتب الموضوع (مثلاً *Why haven't we gone back to the Moon since 1972?*) ← **«ابدأ التصنيع»**.

بعد ما يخلص هتلاقي:
- الفيديو والشورتس والثامبنيل في `output\ready\`.
- في `job.json`، الخانة `ai_images` بتقولك كام صورة اتولدت بالذكاء الاصطناعي. أي صورة فشلت بتترسم ستيك مان بسيط بدالها، عشان الفيديو ما يقفش.

## مشاكل شائعة
- **«ffmpeg مش متسطب»** ← اقفل PowerShell وافتحه تاني بعد التسطيب.
- **الصور كلها ستيك مان** ← اضغط «جرّب توليد صورة» واقرا رسالة الخطأ (غالباً المفتاح غلط أو الرصيد خلص).
- **عايز تشوف اللوحة من الموبايل** ← نفس الواي فاي، وافتح الرابط اللي بيظهر في الشاشة. حط كلمة سر للوحة الأول.
