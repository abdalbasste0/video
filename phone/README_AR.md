# تشغيل مصنع الفيديو على الهاتف (أندرويد) بدون توقف

1. ثبّت من متجر **F-Droid** هذه التطبيقات الأربعة: **Termux** و **Termux:Widget** و **Termux:Boot** و **Termux:API**.
2. افتح Termux واكتب:
   ```bash
   pkg install -y git
   git clone -b claude/capcut-video-factory-system-su2b6s https://github.com/abdalbasste0/video.git ~/video
   bash ~/video/phone/termux_setup.sh
   nano ~/video/.env
   ```
   ضع في ملف `.env`: توكن البوت من @BotFather، ورقمك من @userinfobot. يمكنك إضافة مفتاح Anthropic ومفتاح Pexels إن أردت.
3. **ملف على الشاشة الرئيسية:** اضغط مطولاً على الشاشة الرئيسية ← الأدوات (Widgets) ← **Termux:Widget**. ستظهر الأزرار التالية:
   * 🎬 **Video Factory**: تشغيل المصنع في الخلفية بشكل دائم
   * ➕ **New Video**: تكتب فكرة الفيديو فيُضاف إلى قائمة الانتظار
   * 📊 **Factory Status**: عرض الحالة
   * ⏹ **Stop Factory**: إيقاف المصنع
4. **حتى لا يتوقف أبداً:**
   * من الإعدادات ← التطبيقات ← Termux ← البطارية، اختر **غير مقيّد**. افعل الشيء نفسه مع Termux:Boot و Termux:API.
   * افتح تطبيق **Termux:Boot** مرة واحدة فقط، وبعدها يعمل المصنع تلقائياً بعد كل إعادة تشغيل للهاتف.
   * سكربت المراقبة يعيد تشغيل المصنع تلقائياً إذا تعطّل أو تجمّد، ويبقى إشعار دائم ظاهراً.
5. أرسل للبوت على تيليجرام: `/new فكرتك هنا`. عندما يجهز الفيديو تصلك معاينة وثلاثة أزرار:
   ✅ نشر | ✏️ تعديل | ❌ رفض.
   **لا يُنشر أي فيديو أبداً بدون موافقتك.**

على الهاتف يُصدَّر الفيديو عبر FFmpeg، لأن CapCut Desktop لا يعمل على أندرويد. مسودة CapCut تُحفظ أيضاً بصيغة zip حتى تفتحها وتعدّلها على الكمبيوتر بالأمر:
`python main.py install-draft <ملف.zip>`
